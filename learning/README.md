# 具身智能本科毕设｜机器人视觉与 VLM

这是从 ChatGPT 同名项目迁移到 Codex 的长期学习与毕业设计工作区。

## 项目目标

面向自动化本科毕设，逐步实现一个可演示、可实验、可写论文的机器人视觉项目：

> 自然语言指令 → 视觉/语言理解 → 目标定位 → 运动规划 → 仿真机械臂抓取与放置

暂定题目：**《基于视觉语言模型的机器人视觉感知与自主抓取系统设计与实现》**。

## 三层交付目标

1. 保底版：YOLO/传统视觉 + 目标定位 + 仿真机械臂抓取。
2. 标准版：RGB-D、坐标变换、抓取规划和 MoveIt 2。
3. 冲刺版：加入 VLM，使系统理解“把红色杯子放到蓝色区域”等自然语言指令。

原则是先完成保底闭环，再逐步增强；不从零训练大模型，不把 VLA、强化学习或复杂 6D 位姿估计作为毕业前置条件。
