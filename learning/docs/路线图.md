# 从零到毕设路线图

## 阶段 1：编程基础（第 1–4 周）

- Python 基础与小项目。
- Linux 常用命令、Git、虚拟环境。
- NumPy、Matplotlib。
- OpenCV 图像读取、颜色空间、阈值、轮廓和摄像头。
- 第一个成果：颜色目标检测与中心坐标/轨迹可视化。

## 阶段 2：视觉与深度学习（第 5–12 周）

- PyTorch 张量、Dataset、训练/验证基本流程。
- CNN 基础和迁移学习。
- YOLO 使用、数据标注、训练与评估。
- 成果：桌面物体检测程序和一份实验记录。

## 阶段 3：三维视觉与 ROS 2（第 13–20 周）

- 相机模型、标定、RGB-D、像素到三维坐标。
- ROS 2 节点、Topic、Service、Action、Launch、TF。
- 成果：视觉节点发布目标类别和三维位置。

## 阶段 4：机械臂仿真（第 21–24 周）

- Gazebo/兼容仿真环境、URDF/Xacro。
- MoveIt 2、运动规划、抓取与放置。
- 成果：按程序指定目标完成仿真抓取。

## 阶段 5：VLM 与系统整合（第 25–32 周）

- 理解 VLM 输入输出和提示设计，不从零训练基础模型。
- 将自然语言解析成目标属性与动作，例如 `Pick(红色杯子)`。
- 与检测、定位和抓取模块连接。
- 成果：自然语言驱动的仿真抓取演示。

## 阶段 6：实验、论文与答辩

- 指标：检测准确率、任务成功率、端到端延迟、不同光照/遮挡表现。
- 对比：无 VLM 与有 VLM，或不同检测/提示方案。
- 保留演示视频、运行日志、配置、数据和复现实验步骤。
- 完成论文、PPT、演示脚本和故障降级方案。
