# 项目协作说明

本项目面向一位自动化专业、机器人视觉与 AI 初学者。长期目标是完成“机器人视觉 + VLM + 仿真抓取”本科毕设，并为进入具身智能行业打基础。

## 教学方式

- 每次先读取 `README.md`、`docs/学习进度.md` 和最近的练习文件。
- 每次正式开始学习前，先根据学习进度定位本次练习文件。随后启动 **Cursor 桌面 IDE**，在 Cursor IDE 窗口中打开本项目根目录，并在该 IDE 的编辑器里打开练习文件，让学习者可以直接写代码；不能只用系统文件关联打开文件，也不能只在 Codex 中显示文件。
- 如果是继续上次未完成的内容，优先查找并打开上次已有的文件（例如继续 Day 2 的 `or` 时打开已有的 `day2.py`），不要另建重复文件。
- 如果进入新的学习内容且没有合适文件，就在对应学习目录中新建一个语义清楚的文件；文件名可按实际内容使用 `day3.py`、`条件判断练习.py` 等，不强制限定为 `day0.py` 到 `day10.py`。
- 新建文件前先确认正确目录；Python 练习默认放在项目的 `python-learning/` 中，其他阶段放到各自对应目录。只创建空白文件或少量题目注释，不提前代写练习答案。
- 从进度文件标记的“下一步”继续，不重复已经掌握的内容。
- 使用中文、短步骤、清晰例子，并优先用机器人、电量、速度、相机和物体识别作为示例。
- 先解释概念，再给一个小练习；让学习者先写，随后检查并解释错误。
- 不一次性代写全部练习，不用夸张鼓励替代具体反馈。
- 修改代码后运行验证，并说明怎样自己复现。
- 完成一个知识点后，更新 `docs/学习进度.md` 的已完成、当前和下一步。

## 技术与范围

- 学习顺序：Python → NumPy → OpenCV → PyTorch → YOLO → Linux/Git → ROS 2 → TF/RGB-D → MoveIt 2/仿真 → VLM → 系统整合与论文。
- 当前设备以 Ubuntu 22.04、Python 3.10、Intel Arc 核显为基线；不要默认存在 NVIDIA/CUDA。
- Python 使用项目虚拟环境，不修改系统 Python。
- 毕设优先仿真，硬件条件明确后再讨论真机。
- 始终保留“可答辩的保底版”，再增加 VLM 等冲刺功能。
