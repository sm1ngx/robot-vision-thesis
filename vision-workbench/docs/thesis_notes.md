# 毕设记录

## 当前毕设题目

《基于视觉语言模型的机器人目标理解与抓取系统设计与实现》

## 当前阶段

阶段 2：目标跟踪（基础可运行版本，含手机网络视频流入口）

阶段 1 已完成。阶段 2 实现 CPU 多目标跟踪，保留独立检测入口；不进入阶段 3。

## 当前系统

```text
Camera / Image / Video
→ OpenCV
→ YOLO
→ Object Detection
→ ByteTrack（连续视频/摄像头）
→ Track ID + Center Position + Trajectory
→ MP4 + JSONL
```

当前输出增加单段视频内的跟踪 ID、最近 30 帧的中心轨迹和逐帧 JSONL。类别、置信度、二维 bounding box 与像素中心点继续保留。YOLO11n 和 ByteTrack 均在 CPU 上运行。

## 后续路线

### 阶段 2：目标跟踪（当前已实现）

让系统在连续视频中关联目标身份。验证使用合成移动视频，不代表真实复杂场景中的稳定性已经充分评估。

### 阶段 3：相机标定与位置估计

理解相机内参、畸变、深度与坐标转换，从二维像素逐步获得可用的位置估计。

### 阶段 4：ROS2

将视觉结果封装为 ROS2 节点和消息，建立模块间通信。

### 阶段 5：机器人仿真

在仿真环境中搭建机械臂、相机和工作场景。

### 阶段 6：机械臂抓取

实现运动规划、末端执行器控制和基础抓取流程。

### 阶段 7：VLM 自然语言目标理解

解析自然语言指令，并将语言描述与视觉目标对应起来。

### 阶段 8：完整视觉语言机器人抓取系统

整合自然语言理解、视觉感知、空间定位、ROS2、运动规划和目标抓取。

## 阶段 1 完成标准

- 图片、视频、摄像头三种输入入口存在且参数清晰。
- 使用轻量预训练模型在 CPU 上推理。
- 显示类别、置信度、检测框、中心点；视频与摄像头显示 FPS。
- 图片和视频结果能够保存。
- 摄像头不可用时给出明确错误并安全退出。
- 提供虚拟环境、依赖、运行方法和初学者学习文档。
- 不提前实现 ROS2、VLM、仿真或机械臂功能。

## 阶段 2 实现记录（2026-09-24）

- 方案：YOLO11n + ByteTrack，沿用 CPU PyTorch，只增加 lap 匹配依赖。
- 两个入口：视频跟踪、摄像头跟踪；共同保存 MP4 和逐帧 JSONL。
- 显示目标 ID、类别、置信度、检测框、中心位置、轨迹和处理 FPS。
- 60 帧合成视频测试通过，公交车 50 个有效跟踪帧保持同一 ID，短暂消失前后 ID 连续。
- 8 项单元测试通过，依赖检查无冲突。
- 当时仅验证无设备时的退出路径。随后用户的真实摄像头运行成功保存过约 49 秒、676 帧的可读视频；另一次在显示窗口无响应后中断，窗口稳定性仍待解决。
- 新增手机网络视频流入口，使用本机 MJPEG 测试流实际验证了读取、跟踪和结果保存；尚未连接用户的实际手机。
- ID 切换、遮挡和交叉的真实性能留待后续采集代表性视频评估；不以该功能测试宣称跟踪精度。

详见 `stage2_verification.md`。
