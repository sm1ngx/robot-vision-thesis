# 没有实物时的二维虚拟抓取演示

## 运行

在项目根目录激活 `.venv`，执行：

```bash
python src/simulate_tabletop.py
```

会打印虚拟目标、放置点的平面坐标和一组肩、肘关节角，并在 `results/videos/` 保存 MP4 和同名 JPG。无需 ROS2、Gazebo、MoveIt2 或新的 Python 包。现有 CPU 即可运行。

## 演示的计算

画面左上角是像素原点，虚拟机械臂底座位于 `(90, 260)` 像素。假定比例尺为 `800 像素/米`，所以虚拟目标 `(315, 175)` 对应以底座为原点的平面坐标 `(0.28125, 0.10625)` 米。比例尺完全由代码设定，不是相机标定结果。

演示假设第一连杆长 `0.22` 米、第二连杆长 `0.20` 米。`inverse_kinematics()` 用余弦定理求两关节角，`forward_kinematics()` 从角度算出末端位置。每帧把角度线性插值，再用 OpenCV 绘图。达到目标时动画显示夹爪闭合，把圆点随末端移动到放置点，随后释放。代码拒绝超出臂长的目标。

## 它验证了什么

- 能把一个**预设**的像素点按虚拟比例尺换成二维平面坐标。
- 虚拟两连杆的正、逆运动学在所设目标上相互一致。
- 抓取流程的基本顺序可以在无设备情况下演示。
- 项目源码、输入假设与输出结果可重复运行，适合学习关节角和坐标转换。

## 它没有验证什么

- 未使用手机画面或 YOLO 检测结果来选择目标；所以它不是实际端到端视觉抓取。
- 未标定真实相机，不能把当前 YOLO 的像素中心直接变成机械臂坐标。
- 是二维顶视图；没有物体高度、机械臂三维姿态、障碍物、碰撞、夹持力、重力或控制通信。
- 圆点跟随夹爪是动画规则，不是物理仿真求出的抓取成功率。

后续有了具体机械臂型号和桌面尺寸，可先用其真实连杆与工作空间替换假设，并在相机标定完成后接入视觉坐标。需要更真实的三维验证时再选仿真平台；最终仍要用实物验证标定误差、抓取成功率与安全范围。
